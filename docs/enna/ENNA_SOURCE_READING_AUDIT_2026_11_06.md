## Material findings for Enna's next upgrades

1. **Outcome metrics over vanity CI:** Google Agent Companion prioritizes business metrics (e.g. engagement and revenue), goal success and real task success; agent trajectory, tool use, timing and errors are diagnostic metrics. Enna must not treat 22/22 scripted evals as a successful autonomous business outcome.
2. **Evaluator-optimizer for creative work:** Anthropic's framework supports iterative critique with explicit criteria. Enna needs owner-rated office humor, natural punchlines, usefulness, non-cringe follow CTA and the approved real-photo + hand-drawn doodle aesthetic, with measured performance after publishing.
3. **Memory and reflection:** Generative Agents suggests weighting recency, relevance and importance, synthesizing higher-level reflections. Enna should retain verified operational experiences (failure cause, tool, action, readback) without profiling users or storing secrets.
4. **Observable action selection:** ReAct and Google Agents favor plan/act/observe loops. Enna should escalate after retries, choose alternate scoped safe tools, and read independent provider state before declaring success.
5. **Self-upgrade guardrails:** Claude Code best practices emphasize tests, builds, screenshots, checkpoints and early corrections. Enna should propose isolated PRs with CI, evaluation and rollback, not write arbitrary code to production.
6. **Model training later:** Open source LLM notebooks and certificates teach modeling but training an LLM does not fix Enna's current gaps in provider permissions, data freshness, social action verification or editorial judgment.
